# 実装ステップ：銀行口座（カプセル化・例外処理）

外部から勝手に残高を書き換えられないようにする「データ隠蔽」と、不正な操作を防ぐ「エラーハンドリング」を実装します。

## ステップ1：クラスとフィールドの定義（データ隠蔽の基本）
まずは口座を表現する `BankAccount` クラスを作り、外部から見えないようにデータを定義します。

**やること:**
* `BankAccount` クラスを作成する。
* 以下の3つのフィールドを宣言する。
  * `accountNumber` (String: 口座番号)
  * `name` (String: 名義人)
  * `balance` (int: 残高)

> **ヒント:**
> データ隠蔽（カプセル化）の基本はアクセス修飾子です。外部から直接アクセスさせないため、フィールドにはすべて `private` をつけましょう。

---

## ステップ2：コンストラクタの実装（初期化）
インスタンス（口座）を作るときに、最初の状態をセットする処理を書きます。

**やること:**
* 3つのフィールドの値を引数として受け取り、自身のフィールドにセットするコンストラクタを作成する。

> **ヒント:**
> 引数の変数名とフィールド名が同じになる場合、クラス自身のフィールドを指すために `this.` を使います。（例：`this.balance = balance;`）

---

## ステップ3：Getterメソッドの作成（読み取り専用）
外部から「残高を見る」ことはできても、「残高を直接書き換える」ことはできないようにします。

**やること:**
* 3つのフィールドそれぞれに対して、値を取得するための `get〇〇()` メソッドを作成する。**Setterは作らない**のがポイントです。

> **ヒント:**
> メソッドのアクセス修飾子は外部から呼べるように `public` にします。戻り値の型（Stringやint）を間違えないように注意してください。

---

## ステップ4：depositメソッドの実装（入金とエラーハンドリング）
ただ足し算するだけでなく、「不正な値」をブロックするロジックを入れます。

**やること:**
* 戻り値なし（`void`）で、引数に `int amount` を受け取る `deposit` メソッドを作る。
* もし `amount` が 0未満（マイナス）なら、例外を発生させる。
* 問題なければ、`balance` に `amount` を加算する。

> **ヒント:**
> 例外を意図的に発生させるには `throw new` を使います。
> ```java
> if (amount < 0) {
>     throw new IllegalArgumentException("マイナスの入金はできません");
> }
> ```

---

## ステップ5：withdrawメソッドの実装（出金と複数エラーチェック）
入金よりも少し複雑です。2パターンの不正な操作をブロックします。

**やること:**
* 戻り値なし（`void`）で、引数に `int amount` を受け取る `withdraw` メソッドを作る。
* **チェック①：** `amount` が 0未満なら例外を発生させる（入金と同じ）。
* **チェック②：** `amount` が 現在の `balance` よりも大きい（残高不足）なら、「残高不足です」というメッセージで例外を発生させる。
* どちらのチェックもすり抜けた場合のみ、`balance` から `amount` を減算する。

> **ヒント:**
> 2つの `if` 文（または `else if`）を使って、段階的にエラーチェック（バリデーション）を行います。

---

## ステップ6：Mainクラスでのテスト（try-catchによる動作確認）
作ったクラスが設計通りに動くか、別のクラスから呼び出してテストします。

**やること:**
* 実行用の `Main` クラスを作り、`public static void main(String[] args)` の中で `BankAccount` をインスタンス化（`new`）する。
* 正しい入出金を行って、残高が正しく変わるか（Getterを使って）標準出力で確認する。
* わざとマイナスの入金や、残高以上の出金を行い、例外が発生するか確認する。

> **ヒント:**
> 例外が発生するとプログラムが異常終了してしまいます。例外をキャッチしてメッセージだけを表示するには `try-catch` 構文を使います。
> ```java
> try {
>     // 例外が起きそうな処理（残高1000円なのに1万円引き出そうとする等）
>     account.withdraw(10000);
> } catch (IllegalArgumentException e) {
>     System.out.println("エラー発生：" + e.getMessage());
> }
> ```
